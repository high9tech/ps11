## 📂 هيكلية ملفات المشروع
لضمان عمل الاستضافة بدون مشاكل، يرجى الحفاظ على رفع الملفات داخل المستودع بنفس الأسماء التالية:
1. `index.html` - الواجهة الأساسية والبرمجية التفاعلية.
2. `style.css` - التنسيقات والأنيميشن والمظهر الجمالي المضيء.
3. `cache.manifest` - السكربت الخاص بالتخزين والمزامنة بدون إنترنت.

## ⚙️ طريقة تفعيل الاستضافة على GitHub Pages
1. قم برفع كافة الملفات في مستودع عام (**Public Repository**).
2. توجه لتبويب **Settings** ثم خيار **Pages** من القائمة الجانبية.
3. عند خيار الـ **Branch**، اختر `main` (أو `master`) واضغط **Save**.
4. سيظهر لك رابط الموقع المباشر في الأعلى، قم بنسخه وفتحه داخل متصفح البلاي ستيشن.
